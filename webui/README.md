# 须弥写作 · Web 驾驶舱

本机管理面板：查看进度、管理章节、一键跑校验/导出脚本、生成下一步 AI 指令。
小说的「创作」仍由 AI Skill 完成（Claude Code / OpenCode 里的 `/sumeru-*` 指令），
驾驶舱负责把项目的实时状态和确定性工具摆到你眼前。

零第三方依赖：后端仅 Python 标准库，前端原生 HTML/CSS/JS。

## 启动

```bash
cd <你的小说项目目录>          # chapters/ 和 .sumeru/ 所在目录
python3 <sumeru仓库路径>/webui/server.py
# → http://127.0.0.1:8765
```

可指定端口：`python3 server.py --port 9000`。服务只绑定 127.0.0.1，不暴露局域网。

## 功能

| 页面 | 能力 |
|------|------|
| 仪表盘 | 进度卡、六阶段门禁状态灯、章节字数分布图（过短/过长标色） |
| 章节管理 | 章节列表（命名错误标红）、只读/编辑、实时字数（统一口径）、细纲对照 |
| 工具面板 | 字数统计/章节校验/时间线校验/完稿检查/敏感词扫描/拆书分析一键运行 + 报告查看器 |
| 导出中心 | 平台 × 格式导出（md/txt/html/epub）+ 产物下载 |
| 指令助手 | 按门禁状态推断下一步 `/sumeru-*` 指令，一键复制给 AI 执行 |

## 页面使用说明

### ① 仪表盘（启动默认页）

- **进度卡**：规划章节数（来自 `chapter-plan.json`）、已写章节数（`chapters/` 实际文件）、
  总字数与平均章字数（来自最近一次字数统计）。没跑过统计时显示「—」。
- **门禁状态灯**：deconstruct → outline → write → review → polish → finalize 六个阶段，
  绿=该阶段机器校验通过、红=存在 error、灰=尚未运行。鼠标悬停可看判定依据文件。
  左侧栏底部有同一组状态灯的迷你版，切到任意页面都能瞄一眼。
- **章节字数分布图**：每章一根柱子，绿色区间带内为正常；红柱=过短、黄柱=过长
  （阈值取字数统计时的理想区间）。需要先在工具面板运行一次「字数统计」，
  之后每次运行完图表自动刷新。

### ② 章节管理

- **左侧列表**：按章节号排序，红色条目是命名不符合 `001-标题.md` 规范的文件。
  点章节打开右侧视图。
- **阅读/编辑**：默认只读；点「编辑」进入 textarea，「保存（自动备份）」写回
  `chapters/` 原文件。顶部实时显示字数（与后端口径一致：剥离「第X章」标题行后，
  汉字+英文单词计数）。
- **自动备份规则**：某章第一次被修改保存时，最初原稿存入
  `.sumeru/write/original/`（之后永不覆盖）；每次保存前的版本另存到
  `.sumeru/write/history/save-{时间戳}/`，可逐级回滚。
- **细纲对照**：章节下方灰底面板显示该章细纲（核心事件/爽点/悬念/推进节点），
  方便核对正文是否按纲走。数据来自 `chapter-outlines.json`。

### ③ 工具面板

六张工具卡对应六个脚本，参数已预填默认值，改完点「运行」：

| 工具卡 | 脚本 | 典型用法 |
|--------|------|----------|
| 字数统计 | `chapter-word-counter.py` | 日常看字数分布；改「理想区间」适配平台（如番茄 2000-3000） |
| 章节结构校验 | `check-chapters.py` | 查缺章/命名/空章/占位符；细纲路径留默认即可对照细纲 |
| 时间线校验 | `validate-timeline.py` | review 阶段产出 timeline.json 后验算时序/年龄 |
| 完稿检查/导出 | `build.py` | 勾「仅检查不导出」做发布前体检；取消勾选即执行导出 |
| 敏感词扫描 | `sensitive-scan.py` | 按自维护词表扫描，命中明细看报告 |
| 拆书分析 | `analyze-book.py` | 填原作文件或章节目录，产机械统计 |

- **运行结果区**：绿色徽章=退出码 0，红色=检查不通过或脚本报错（输出原样展示），
  黄色=超时被终止。工具串行执行，同一时刻只有一个在跑。
- **报告查看**：五个 Tab 对应常用报告文件，点击即渲染（表格/列表已做格式化）。
  报告不存在会提示先运行对应工具。

### ④ 导出中心

1. 选平台（全平台/起点/番茄/晋江/纵横/17K）与格式（默认 `md,txt,html,epub`）
2. 填书名与作者（可选，用于扉页），点「导出」
3. 导出走 `build.py`，全书导出约需数十秒；完成后下方列出可直接点击下载的产物
   （`publish/{平台}/full.md|txt|html|epub`）
4. 导出前置条件是完稿检查无 error——若门禁红灯，先回工具面板跑「完稿检查」看错误清单

### ⑤ 指令助手

- 页面顶部自动给出**下一步建议**：按门禁状态推断（如「尚无细纲 → 先 `/sumeru-outline`」、
  「有章节未完稿 → 先 `/sumeru-review`」），点「复制指令」后到 Claude Code / OpenCode
  粘贴执行即可
- 下方的**常用指令速查**是全流程七个环节的命令备忘
- 典型工作循环：AI 写完一卷 → 回驾驶舱看仪表盘与字数 → 跑章节校验 →
  复制指令让 AI 进入下一卷 → 全部完成后在导出中心交付

## 安全与数据

- 所有文件读写限制在 `chapters/`、`.sumeru/`、`publish/` 白名单内，路径穿越返回 403
- 章节保存自动备份（与全局规则一致）：最初原稿存 `.sumeru/write/original/`（只存一次），
  每次保存前的版本存 `.sumeru/write/history/save-{时间戳}/`
- 无数据库、无缓存：界面数据每次从 `.sumeru/` 现算，与 CLI/Agent 侧操作实时一致
- 工具执行串行化（同一时刻一个脚本），60 秒超时（导出 300 秒）
